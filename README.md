# Decision Twin 🌍

### Free, Open-Source, Multilingual Decision Support Platform

**Founded by Fatih Er**

Decision Twin is a free, open-source project designed to help people think through important decisions with clarity.

Our mission is to make structured decision support accessible to everyone, regardless of language, location, or income.

## 🌐 Live Application
https://fm-er.github.io/decision-twin/

## ✨ Current Features
- Free browser-based decision comparison
- Five languages: Turkish, English, Arabic, Russian, and Spanish
- Business, career, financial, education, travel, and everyday decisions
- Structured questions, trade-offs, and next-step suggestions
- No account required
- No paid AI API required

## 🧠 Our Vision
We aim to develop an accessible, multilingual AI decision assistant that can run on users' own devices wherever technically possible.

**Important:** The current v0.2 prototype uses rule-based analysis. It does not yet contain a connected AI model.

## 🤝 Contribute
Developers, designers, translators, and researchers are welcome to contribute.

You can help with:
- On-device open-source AI integration
- New languages and accessibility
- Decision analysis methods
- Privacy and security
- Mobile performance and user experience

Please open a GitHub Issue to suggest an improvement or submit a Pull Request with your proposed changes.
