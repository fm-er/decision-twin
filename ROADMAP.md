# Decision Twin — Development Roadmap 🌍

Decision Twin is a free, open-source, multilingual decision-support platform founded by Fatih Er.

Our mission is to make decision-support tools accessible to everyone, without subscription fees or mandatory accounts.

## Phase 1 — Improve the Platform
- Improve the mobile user experience.
- Add more languages.
- Improve decision comparisons and explanations.
- Add accessible design and dark/light themes.

## Phase 2 — Free On-Device AI
- Evaluate WebLLM and Transformers.js.
- Integrate a suitable open-source AI model where supported.
- Keep user decisions private and processed locally.
- Provide a rule-based fallback for unsupported devices.

## Phase 3 — Community Development
- Welcome developers, designers, translators, and testers.
- Collect feedback through GitHub Issues and Discussions.
- Review community contributions through pull requests.
- Publish transparent development milestones.

## Phase 4 — Global Growth
- Improve offline support and performance.
- Make Decision Twin easier to share worldwide.
- Keep the core platform free and open-source.

## How to Contribute
1. Try the application.
2. Open a GitHub Issue to report a bug or suggest a feature.
3. Discuss ideas with the community.
4. Submit a pull request for review.
