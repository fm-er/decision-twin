# Contributing to Decision Twin

Welcome! Thank you for helping develop Decision Twin, a free, open-source, multilingual decision-support platform.

## Getting Started

1. Fork this repository to your GitHub account.
2. Download or clone the project.
3. Open index.html in your browser.
4. Create a separate branch for your changes.
5. Test your changes and submit a Pull Request.

## What We Need

- Free on-device AI integration
- New languages and translations
- Better decision analysis
- Mobile and desktop improvements
- Accessibility and privacy improvements
- Bug fixes and testing

## Important Rules

- Do not upload passwords or API keys.
- Do not introduce mandatory paid APIs.
- Keep the application usable without AI.
- Respect user privacy.
- Explain all proposed changes.
- Be respectful to other contributors.
